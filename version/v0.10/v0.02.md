# v0.02

## Additions
- You can now execute real shell commands (except the ones that aren't built in like cd, alias, or time)
- Shortened the path, now you will only see the current directory you're in (type 'pwd' if you want to see the path yourself)
- Added custom commands (help, jmp, exit). Type help or help (command) to explain a specific command clearly.

- Tokenizer not parsing unfinished quotation marks properly **PATCHED**
- Memory Leaks caused by not freeing the tokens before a quotation mark. **PATCHED**
